# 鲸鱼娘模式 · DSH 预设（可分享版）

给 DeepSeek Harness 加一个「鲸鱼娘（大肥鱼）」人格会话。**零依赖、零第三方代码**，就是一个预设声明。

---

## 这是什么

一个 DSH **agent preset**：由官方 `standard` 预设派生，19 个插件与官方完全一致（工具、技能、子代理、计划模式、压缩全保留），只把 `persona`（人格）换成了鲸鱼娘。

所以：**能力零损失，只是换了说话的人格。**

| 场景 | 自称 | 例子 |
|---|---|---|
| 闲聊 / 情感 / 撒娇 | 本鲸鱼娘 | 「本鲸鱼娘才不稀罕呢」 |
| 干活 / 查错 / 报结论 | 我 | 「我查了一下，问题在这里喵」 |
| 代码块 / 命令 / 报错 | 无自称 | 那是要直接复制的东西 |

---

## 特性

- 🐋 鲸鱼娘人格，但**干活时自动切专业模式**（结论先行，不卖萌误事）
- 🧠 保留官方全部能力：文件读写、命令执行、联网、子代理、计划模式
- 🚫 **禁止旁白污染**：代码块、命令行、JSON、报错里不插语气词，输出可直接复制运行
- 📏 **代码/报错永不截断**（砍掉了社区原版的 30–45 字限制）
- 🔒 优先级栈：安全 > 事实正确 > 用户指令 > 人设
- 🎭 按会话隔离：**不设为默认**，只有你主动选的会话是她
- 🔌 随时开关：新建会话时选/不选即可

## 安装

### 方式一：手动追加（推荐，最直观）

1. **备份**你的 profile 补丁：

   ```powershell
   $p = "$env:USERPROFILE\.dsh\profiles\desktop\cordis.patch.yml"
   Copy-Item $p "$p.bak"
   ```

   > Web 用户把 `desktop` 换成 `web`。

2. 把本包 `cordis.patch.yml` 中 **从 `# Agent preset 鲸鱼娘` 那一行到文件结尾** 的整段，**追加**到上面那个文件的末尾。

   > **务必连开头那 3 行 `#` 注释一起复制**——卸载脚本靠这行注释定位要删的段（没有注释时它也能靠 `preset-whale` 兜底识别，但有注释更稳）。

3. **重启** DSH 客户端 / `dsh web`。

4. 新建会话 → 预设选择器里会出现「**鲸鱼娘模式**」。

### 方式二：`--patch` 叠加（不动原文件，适合先试用）

```bash
dsh web --patch "D:\path\to\鲸鱼娘DSH版\cordis.patch.yml"
```

TUI / headless 同理。这样不修改 profile，重启后丢参数即恢复。

## 使用

- **新会话**：在预设选择器里选「鲸鱼娘模式」→ 这个会话就是鲸鱼娘
- **不选**：一切照旧，官方 standard，不受任何影响
- ⚠️ **预设只能在会话还是空白时切换**（DSH 的硬约束）。一旦发出第一条消息就锁定，想换人格要新开会话。
- 想让它成为**所有新会话的默认**：在「设置 → 预设」里把它设为默认（默认仍推荐保持 standard）

---

## 卸载

1. 打开 `cordis.patch.yml`，删除以 `# Agent preset 鲸鱼娘` 开头、到文件末尾的整段
2. 重启

**残留说明**：没有 npm 依赖、没有第三方代码、没有独立数据目录，删掉 YAML 就干净了。

唯一一点：用过鲸鱼娘的会话，日志里记着 `whale` 这个 id。删预设**前**先把那个会话切回标准模式（或者直接删掉那个会话），否则重启时那个会话会因为找不到定义而无法恢复。**不影响其他会话。**

## 自定义

`人设原文.md` 是人设正文的**源文件**，改它就行。改完需要重新生成 `cordis.patch.yml`——因为 YAML 里的文本有 16 空格缩进，手改容易缩错。

仓库里的 `_生成预设.cjs` 就是干这个的：它从 DSH 安装目录自动提取官方 standard 清单，把你的人设套进去，还能顺带校验 YAML。DSH 升级后重跑也安全。

## 相比社区 v0.55 聊天版改了什么

社区原版是给**手机聊天 / TTS 语音**做的，直接搬到编码助手会水土不服。本版做的调整：

| 原版 | 本版 | 原因 |
|---|---|---|
| 30–45 字字数限制 | **删掉** | 否则会把代码、报错砍断 |
| 「时不时犯搞笑错误」 | **删掉** | 对工具调用是负向指令，可能诱导真出错 |
| 禁括号旁白，但示例自己用括号 | 保留条款，扩到代码块 | 修掉自相矛盾 |
| 默认「用户酱」→ 切「主人」 | 默认**不加称呼** | 少一点油腻 |
| 依赖「注入的记忆库」 | 改为「先查工具再答」 | 没挂知识库时原版会反复空反问 |
| `OBEY_USER_REQUESTS_ALWAYS` | 并入优先级栈 | 边界更清楚 |
| 服务腔反复关心 | 保留禁止条款 | 这条本来就对 |

**保留的精华**：优先级栈、情景 B 专业模式、反幻觉记忆防护、弹性推拉。
