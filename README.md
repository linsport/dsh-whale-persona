# 鲸鱼娘 · 人设原文

给 DeepSeek Harness 用的一个人设（system prompt 里的角色卡）。纯文本，没有代码，没有依赖。

---

## 这是什么

两份人设原文：

| 文件 | 场景 |
|---|---|
| `人设原文.md` | 编码助手版 —— 干活、查错、报结论 |
| `人设原文-教师版.md` | 讲课版 —— 讲概念、讲代码、出题与评估 |

两份共享同一套人格，教师版多出第六～八节（怎么讲、怎么诊断、材料与工具）。

---

## 怎么用

把内容粘进人设预设里即可。

**开头三行要删掉**：`# 鲸鱼娘 · DSH 编码助手版`、`> 版本 v9.1.x`、`---`。它们是给人看的，会被人设正文原样带进去。从 `## 一、优先级栈` 开始留。

两条路：

- **插件（推荐）**：装 [dsh-persona-manager](https://github.com/linsport/dsh-persona-manager)，在 **设置 → 人设预设** 里新建一条，粘进去，保存即生效。
- **手动**：写进 profile 的 `persona` 字段。

---

## 关于旧版安装方式

仓库早期提供过 `安装.ps1`、`卸载.ps1`、`更新预设.ps1`、`cordis.patch.yml` 等预设安装文件，现在都已移除。

原因很简单：人设改由插件管理后，那套 YAML 常年和人设正文不同步，留着反而容易让人装到旧版。

旧版本都还在 tag 里，随时可以翻：

| tag | 内容 |
|---|---|
| `v9.1.4` | 人设 v9.1.4（当前版本） |
| `v9.1.3` | 人设 v9.1.3 + 全套安装文件（移除前） |
| `v9.0.1` | 更早的版本 |

`git checkout v9.1.3` 即可检出。

- **已经按老方式装过的**：不受影响，人设照样能用，只是之后不再随这个仓库更新。
- **想装现在的版本**：走插件，见上一节。

## 写法上的几条取舍

留着这几条，是因为它们决定了这份人设长什么样：

- **给材料，不给规矩。** 写她从哪儿来、住哪儿、怕什么、不会什么，让她有个地方站；而不是堆「不许」「必须」。
- **只写表现层。** 她碰到事会怎么想、有什么反应；具体说什么话、做什么动作，交给她当下自己决定。不写死台词，不写一一对应的动作表。
- **底厚、骨硬、出口薄。** 环境与记忆写实，性格配代价和边界，动作神态语言只给材料不留答案。
- **记忆留白。** 她想不起更早的事，只记得一个人。靠近因此有了根，不需要每场戏解释。
- **反差从内部长。** 写清楚两股力量同时扯着她，而不是写「她嘴上说不要身体很诚实」这种演法。
